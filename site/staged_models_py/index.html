    Pydantic models

    The PyDantic models are used to validate and parse the JSON data received by the FastAPI web server.

    staged_models

    CLASS DESCRIPTION
    NewJob

    Used by the 'new job' endpoint to pass in the job ID and either a list of files, or a telescope specific structure
    FileStatus

    Used by the 'File status' endpoint to pass in the a list of files.
    FileStatusResult

    Used by the 'File status' endpoint to return the status of the queried files
    JobResult

    Used by the dummy ASVO server endpoint to pass in the results of a job once all files are staged.
    StageFiles

    Used by the dummy ASVO server endpoint to pretend to stage jobs.
    JobStatus

    Used by the 'read status' endpoint to return the status of a single job.
    GlobalStatistics

    Used by the 'get stats' endpoint to return the kafka/kafkad/staged status and health data.
    JobList

    Used by the 'list all jobs' endoint to return a list of all jobs.
    ErrorResult

    Used by all jobs, to return an error message if the call failed.
    ScoutFileStatus

    Used by the Scout API dummy status endpoint, to return the status of a single file.
    ScoutLogin

    Used by the dummy Scout API login endpoint, to pass username/password
    ScoutLoginResponse

    Used by the dummy Scout API login endoint to return the token

    Used by the 'new job' endpoint to pass in the job ID and either a list of files, or a telescope specific structure defining an observation, where all files that are part of that observation should be staged.

    TYPE: Optional[list[str]]

    notify_url

    URL to call to notify the client about job failure or success

    TYPE: str

    obs

    Telescope-specific structure defining an observation whose files you want staged

    TYPE: Optional[MWAObservation]

    job_id: int

    Used by the 'read status' endpoint to return the status of a single job.

    The files attribute is a list of (ready:bool, readytime:int) tuples where ready_time is the time when that file was staged (or None)

    ATTRIBUTE DESCRIPTION
    job_id

    Integer ASVO job ID

    TYPE: int

    created

    Integer unix timestamp when the job was created

    TYPE: Optional[int]

    completed

    True if all files have been staged

    TYPE: Optional[bool]

    total_files

    Total number of files in this job

    TYPE: Optional[int]

    ready_files

    Number of files successfully staged

    TYPE: Optional[int]

    error_files

    Number of files where Kafka returned an error

    TYPE: Optional[int]

    last_readytime

    Integer unix timestamp of the last time a file was staged

    TYPE: Optional[int]

    files

    key is filename, value is tuple(bool, bool, int), which contains (ready, error, readytime)

    TYPE: dict[str, tuple]

    Attributes

    job_id instance-attribute 
    job_id: int
    created class-attribute instance-attribute 
    created: Optional[int] = None
    completed class-attribute instance-attribute 
    completed: Optional[bool] = None
    total_files class-attribute instance-attribute 
    total_files: Optional[int] = None
    ready_files class-attribute instance-attribute 
    ready_files: Optional[int] = None
    error_files class-attribute instance-attribute 
    error_files: Optional[int] = None
    last_readytime class-attribute instance-attribute 
    last_readytime: Optional[int] = None
    files class-attribute instance-attribute 
    files: dict[str, tuple] = {'': (False, False, 0)}

    TYPE: int

    ready_files

    Total number of files staged so far

    TYPE: int

    error_files

    Number of files where Kafka returned an error

    waiting_files

    Number of files we are waiting to be staged

    TYPE: int

    availdatasz

    scoutfs available data capacity

    TYPE: Optional[int]

    health

    scoutfs health of filesystem: 0-unknown, 1-ok, 2-warning, 3-error

    TYPE: Optional[int]

    healthstatus

    TYPE: Optional[str]

    releaseable

    TYPE: Optional[int]

    TYPE: Optional[int]

    TYPE: Optional[int]

    ATTRIBUTE DESCRIPTION

    TYPE: bool

    First file name for file, for policy decisions, eg "/object.dat.0"

    TYPE: str

    size

    File size in bytes, eg "10485760"

    TYPE: int

    inode

    File inode number, eg "2"

    TYPE: int

    uid

    User ID for file, eg "0"

    TYPE: int

    username

    User name for file, eg "root"

    TYPE: str

    gid

    group ID for file, eg "0"

    TYPE: int

    groupname

    group name for file, eg "root"

    TYPE: str

    mode

    file mode, eg 33188

    TYPE: int

    modestring

    file mode string, eg "-rw-r--r--"

    TYPE: str

    nlink

    number of links to file, eg 1

    TYPE: int

    atime

    access time, eg "1618411999"

    TYPE: int

    mtime

    modify time, eg "1618411968"

    TYPE: int

    ctime

    attribute change time, eg "1618415117"

    TYPE: int

    rtime

    residence time, eg "1618415102"

    TYPE: int

    version

    Data version, eg "2560"

    TYPE: str

    onlineblocks

    Number of online blocks, eg "2560"

    TYPE: int

    offlineblocks

    Number of offline blocks, eg "0"

    TYPE: int

    flags

    archive flags, eg "0"

    TYPE: int

    flagsstring

    archive flags string, eg ""

    TYPE: str

    uuid

    UUID for file, eg "8e9825f9-291d-415e-bb1f-38d8f865dcac"

    TYPE: str

    copies

    Complex sub-structure that we'll ignore for this dummy service

    TYPE: list
